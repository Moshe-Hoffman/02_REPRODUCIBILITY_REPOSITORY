# Restored-case sensitivity inputs

These minimized, model-ready files reproduce the final cross-study sensitivity
table in the Supplementary Information. Run `python3 reproduce_sensitivity_results.py`
from the repository root.

The files restore three later runs in Study 2, three later completed sessions in
Studies 3 and 4, two assistance-screen cases in Study 5, and six
assistance-screen cases in Study 6. They contain only the variables needed for
the table's specified regressions and repository-local anonymous row or
participant keys. They do not contain Prolific identifiers, session or study
identifiers, timestamps, IP or device metadata, arguments, feedback, or other
platform fields.

These files intentionally differ from the canonical study datasets, which
continue to represent the manuscript's final analysis samples.
